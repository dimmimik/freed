# Expense Tracker

Expense Tracker is a small Python application for recording and analyzing personal expenses.

Instead of focusing on a database, this project demonstrates a modular architecture where expense records are loaded, filtered, summarized and exported into a readable report.

## Features

- Expense list
- Categories
- Monthly summary
- Category statistics
- Total spending
- Report export

## Example

```
Food        $24.90
Transport   $12.00
Books       $31.50
Coffee      $4.80

Total

$73.20
```

Run

```bash
python app.py
```
